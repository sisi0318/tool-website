# 数据旅程 (Data Journey)

## 一句话定位

粘贴任何数据,系统告诉你它是什么、下一步能做什么;你每点一下,数据变换一次;**走过的路自动变成一条可保存、可分享、可套用到新数据的流程**。

## 与现有能力的关系(为什么不是重复建设)

| | 工具页 (/tools) | 画布 (/canvas) | 数据旅程 (/journey) |
|---|---|---|---|
| 主角 | 单个工具 | **工具**(先摆节点再连线) | **数据**(先有数据再走路) |
| 心智模型 | 表单 | 流程图(n8n 式) | 探索 / 寻路(git 式历史树) |
| 流程从哪来 | 无流程 | 用户预先编排 | **探索的副产品,零编排成本** |
| 适合 | 明确知道用哪个工具 | 复杂分支、多输入工作流 | "我拿到一坨不知道是什么的数据" |
| 门槛 | 低 | 高 | 极低(全程点选) |

三者共用同一套 66 个节点适配器(`lib/adapters`),旅程可一键"升级"到画布继续深度编辑。

## 核心创新点

1. **范式反转**:CyberChef / n8n / 画布都是"算子为节点、数据在线上流";旅程反过来——**数据状态是节点,变换是边**。用户从不"搭建"任何东西。
2. **感知 → 建议 → 一步**:每个数据状态自动经过智能识别(复用 `data-detector`:JWT/Base64/JSON/时间戳/PEM/CSV/Hex/URL 编码…),按识别结果给出排序后的"下一步"建议芯片,一键应用带预设配置(如"Base64 解码"直接带 `mode:decode`)。
3. **可分叉的历史树**:任何一步都能回到之前的状态尝试另一条路,形成旅程树;分支之间可对照。相当于给数据做 git。
4. **足迹即配方**:根到当前节点的路径就是一条流程,可以:
   - **回放**:换一份新数据,一键重跑整条路径;
   - **分享**:路径(仅变换步骤,不含数据,天然隐私安全)编码进 URL,别人打开即可对自己的数据复用;
   - **升级**:导出为画布工作流继续编辑。

## 用户故事

- 开发者从日志里复制出一串 `eyJhbGci...` → 粘贴 → 识别为 JWT(置信度 95%)→ 点"解码 JWT" → 看到 payload → 点"格式化 JSON" → 点"JSON Path 提取" 取出 `exp` → 点"时间戳转时间"。整条路径自动保存;下次再遇到 token,打开旅程点"应用到新数据"即可。
- 运营同学收到一张九宫格图 → 上传 → 识别为图片 → 点"切图打包" → 下载 ZIP。
- 安全同学分享一条"Base64 解码 → gzip 解压 → JSON 格式化"的 URL 给同事,同事贴上自己的样本直接得到结果。

## 界面结构(移动优先)

```
┌──────────────────────────────┐
│ 旅程名  [保存][分享][画布][新建] │  ← 顶栏
├──────────────────────────────┤
│ ①输入 → ②Base64解码 → ③JSON格式化│  ← 足迹条(横向滚动,可点跳转,
│              └ ⑵分支×2          │     有分叉的节点显示分支标记)
├──────────────────────────────┤
│ ┌──────────────────────────┐ │
│ │ 当前数据卡                │ │  ← 类型徽章 + 识别芯片(置信度)
│ │ [JSON 92%] [文本]         │ │     智能预览(文本/JSON树/图片)
│ │ {"user":"...", ...}       │ │     复制 / 下载 / 编辑
│ └──────────────────────────┘ │
├──────────────────────────────┤
│ 下一步可以…                   │
│ [格式化 JSON] [JSON Path 提取]│  ← 建议芯片(识别驱动,一键应用)
│ [转 YAML] [计算哈希] [更多⌄]  │     "更多"打开全量兼容工具选择器
└──────────────────────────────┘
```

- 足迹条上的每一步可点开:查看/修改该步配置(修改后沿当前路径向下重跑)。
- 分支抽屉:树形列出所有探索分支,点击切换。

## MVP 范围

- 输入:粘贴文本 / 上传文件 / 内置示例
- 识别 + 建议引擎(识别驱动的精选建议 + 类型兼容的全量兜底)
- 单步应用、足迹条、回退分叉、分支抽屉
- 步骤配置查看与修改(沿当前路径重跑)
- 旅程保存/加载(localStorage)、路径 URL 分享、应用到新数据(回放)
- 导出当前路径到画布
- 不含:多输入合流(去画布)、协作、云端存储

## 边界与原则

- **隐私**:分享 URL 永不包含数据本体(除非用户明确勾选携带 ≤2KB 的文本输入);识别与变换全部本地执行。
- **诚实**:建议按置信度排序并显示识别依据;无把握时只给通用兼容建议。
- **不越权**:有网络副作用的节点(如 HTTP 请求)不进入自动建议。
