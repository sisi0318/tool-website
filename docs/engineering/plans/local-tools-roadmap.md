# 本地工具与交互增强

按可独立验证的功能分批提交。已有页面、画布节点和数据旅程应复用同一处理函数；新增文案提供中英文，文件处理不上传用户数据。

## 实施顺序

1. Protobuf 深度检查器
   - [x] 公共编解码内核、大整数精度、重复字段、错误偏移、画布 Schema 编解码
   - [x] 字段元数据、Hex 联动、无 Schema 字段解释切换
2. [x] JSON/YAML 结构化 Diff：路径差异、忽略字段、数组按键对齐
3. [x] 结果继续处理：工具输出／子树送入数据旅程，保留二进制类型
4. [x] JSON 树：紧凑视图、按层展开、搜索、复制路径、聚焦子树
5. 文件压缩
   - [x] 有大小限制和校验的二进制编解码、ZIP 目录／提取／打包内核
   - [ ] ZIP 文件浏览、选择性提取、多文件打包页面及二进制节点
6. [ ] CSV/JSONL 日志：筛选、排序、分组计数、错误行和结果导出
7. [ ] Unicode 字符检查：码点、UTF-8、不可见字符和规范化
8. [ ] 文本行处理：去重、排序、空白清理、前后缀、列提取和集合操作
9. [ ] URL 参数编辑：拆解、重复参数、解码和重新组装
10. [ ] MessagePack/CBOR：浏览器本地编解码和特殊类型表示
11. [ ] SQLite：本地文件、表结构、查询和数据导出
12. [ ] PDF：合并、拆分、重排、旋转、图片生成和页码

## Protobuf 内核

`lib/protobuf-tools.ts` 同时供页面和适配器使用。无 Schema 结果中，安全范围内的整数仍为 number，超出的整数为十进制字符串；有 Schema 的 64 位整数按 Protobuf JSON 规则表示为字符串，bytes 表示为 Base64。无 Schema 编码不猜测数字字符串的类型，精确的 int64/uint64 编码应提供 Schema。

画布无 Schema 输出保留 `field_1` 等原有根键，新增 Hex 输出端口。嵌套类型识别只接受完整合法的消息；非法根消息报告错误及字节偏移，不返回部分成功结果。处理设有字节数、字段数、递归深度及分析工作量上限。

检查器按每次字段出现的位置保存解释选择，支持有符号整数、ZigZag、浮点数、UTF-8、Base64 字节、嵌套消息和 packed 数组。字段和 Hex 可双向定位，标签与载荷分别高亮；可复制字段或载荷 Hex，下载原始载荷。字段与字节分页显示，失败的类型切换保留原结果。Schema 模式只检查 wire 数据，上方 JSON 始终遵循 Schema。

## 结构化 Diff

`lib/structured-diff.ts` 同时供 Diff 页面和画布节点使用。JSON/YAML 对象忽略键顺序；对象数组可按唯一字段对齐，普通值数组按位置比较。忽略规则支持点路径、JSON Pointer 和 `*` / `**` 通配符。报告同时保留可读路径及原始／新数据的 JSON Pointer；新增和删除对象按叶字段报告，结果按页显示，导出完整 JSON。

拒绝循环 YAML、重复匹配键、不安全整数与超限输入，避免不明确的对齐或精度损失。模式切换保留输入与结构化比较设置；较大输入手动运行。画布原文本模式的输出结构保持兼容，新增 `changed` 字段计数输出。

## 结果继续处理

通用工具输出、编码工具、结构化 Diff 报告、JSON 树节点以及 Protobuf JSON／编码结果／原始载荷可继续到数据旅程，或先选择兼容工具。工具选择器按需加载；接收后先配置所选工具，点击运行才执行。未保存的旅程草稿可返回恢复，只有用户选择开始新旅程才替换。

`lib/tool-transfer.ts` 通过当前标签页内存传递数据，URL 片段只带一次性随机句柄，接收后立即移除。句柄 5 分钟过期，最多保留 8 份／128 MB；单份文件最多 64 MB，文本／JSON 最多 8M 字符。字节视图按有效范围复制成 File，JSON 值在发送时复制。旅程继续沿用已有草稿保存机制，文件不持久化；其输入转换复用画布规则，避免对象退化为 `[object Object]`。

## JSON 树交互

共享 `JsonTreeView` 默认紧凑视图，可切换卡片视图；支持 0—4 层／全部展开、键值搜索、复制 JSONPath／JSON Pointer 和聚焦子树。搜索显示匹配节点与祖先，匹配容器时可查看其内容。字符串只渲染预览，复制和继续处理使用完整值。

`lib/json-tree.ts` 以 JSON Pointer 标识节点，避免点号、斜杠等键名引起路径冲突；迭代索引最多 20,000 节点／128 层，按 100 项分页渲染。JSONPath 适配器同时修复转义引号、反斜杠和 Unicode 键名解析，树中复制的路径可直接用于提取。

## 文件压缩内核

`lib/compression-files.ts` 在字节层处理 GZip、Zlib、Deflate 和 Brotli。DEFLATE 系列使用有背压的 Worker，Brotli 使用有输出大小限制的 WASM 流；均可取消。GZip 逐成员校验 CRC／长度，Zlib 校验 Adler-32。

`lib/zip-tools.ts` 先读目录元数据，按选定项提取并核对 CRC32 和长度；打包时逐文件压缩。支持 ZIP64 元数据、UTF-8／CP437／GB18030 文件名及 Unicode Path 扩展，拒绝越界和分卷记录；加密、未知压缩方法、不安全路径或过大文件可列出但不可提取。单文件／归档输入上限 64 MB，解压或打包数据合计上限 128 MB，最多 2,000 项。
