# 本地工具与交互增强

按可独立验证的功能分批提交。已有页面、画布节点和数据旅程应复用同一处理函数；新增文案提供中英文，文件处理不上传用户数据。

## 实施顺序

1. Protobuf 深度检查器
   - [x] 公共编解码内核、大整数精度、重复字段、错误偏移、画布 Schema 编解码
   - [x] 字段元数据、Hex 联动、无 Schema 字段解释切换
2. [x] JSON/YAML 结构化 Diff：路径差异、忽略字段、数组按键对齐
3. [x] 结果继续处理：工具输出／子树送入数据旅程，保留二进制类型
4. [x] JSON 树：紧凑视图、按层展开、搜索、复制路径、聚焦子树
5. 文件压缩
   - [x] 有大小限制和校验的二进制编解码、ZIP 目录／提取／打包内核
   - [x] ZIP 文件浏览、选择性提取、多文件打包页面及二进制节点
6. [x] CSV/JSONL 日志：筛选、排序、分组计数、错误行和结果导出
7. [x] Unicode 字符检查：码点、UTF-8、不可见字符和规范化
8. [x] 文本行处理：去重、排序、空白清理、前后缀、列提取和集合操作
9. [x] URL 参数编辑：拆解、重复参数、解码和重新组装
10. [x] MessagePack/CBOR：浏览器本地编解码和特殊类型表示
11. [ ] SQLite：本地文件、表结构、查询和数据导出
12. [ ] PDF：合并、拆分、重排、旋转、图片生成和页码

## Protobuf 内核

`lib/protobuf-tools.ts` 同时供页面和适配器使用。无 Schema 结果中，安全范围内的整数仍为 number，超出的整数为十进制字符串；有 Schema 的 64 位整数按 Protobuf JSON 规则表示为字符串，bytes 表示为 Base64。无 Schema 编码不猜测数字字符串的类型，精确的 int64/uint64 编码应提供 Schema。

画布无 Schema 输出保留 `field_1` 等原有根键，新增 Hex 输出端口。嵌套类型识别只接受完整合法的消息；非法根消息报告错误及字节偏移，不返回部分成功结果。处理设有字节数、字段数、递归深度及分析工作量上限。

检查器按每次字段出现的位置保存解释选择，支持有符号整数、ZigZag、浮点数、UTF-8、Base64 字节、嵌套消息和 packed 数组。字段和 Hex 可双向定位，标签与载荷分别高亮；可复制字段或载荷 Hex，下载原始载荷。字段与字节分页显示，失败的类型切换保留原结果。Schema 模式只检查 wire 数据，上方 JSON 始终遵循 Schema。

## 结构化 Diff

`lib/structured-diff.ts` 同时供 Diff 页面和画布节点使用。JSON/YAML 对象忽略键顺序；对象数组可按唯一字段对齐，普通值数组按位置比较。忽略规则支持点路径、JSON Pointer 和 `*` / `**` 通配符。报告同时保留可读路径及原始／新数据的 JSON Pointer；新增和删除对象按叶字段报告，结果按页显示，导出完整 JSON。

拒绝循环 YAML、重复匹配键、不安全整数与超限输入，避免不明确的对齐或精度损失。模式切换保留输入与结构化比较设置；较大输入手动运行。画布原文本模式的输出结构保持兼容，新增 `changed` 字段计数输出。

## 结果继续处理

通用工具输出、编码工具、结构化 Diff 报告、JSON 树节点以及 Protobuf JSON／编码结果／原始载荷可继续到数据旅程，或先选择兼容工具。工具选择器按需加载；接收后先配置所选工具，点击运行才执行。未保存的旅程草稿可返回恢复，只有用户选择开始新旅程才替换。

`lib/tool-transfer.ts` 通过当前标签页内存传递数据，URL 片段只带一次性随机句柄，接收后立即移除。句柄 5 分钟过期，最多保留 8 份／128 MB；单份文件最多 64 MB，文本／JSON 最多 8M 字符。字节视图按有效范围复制成 File，JSON 值在发送时复制。旅程继续沿用已有草稿保存机制，文件不持久化；其输入转换复用画布规则，避免对象退化为 `[object Object]`。

## JSON 树交互

共享 `JsonTreeView` 默认紧凑视图，可切换卡片视图；支持 0—4 层／全部展开、键值搜索、复制 JSONPath／JSON Pointer 和聚焦子树。搜索显示匹配节点与祖先，匹配容器时可查看其内容。字符串只渲染预览，复制和继续处理使用完整值。

`lib/json-tree.ts` 以 JSON Pointer 标识节点，避免点号、斜杠等键名引起路径冲突；迭代索引最多 20,000 节点／128 层，按 100 项分页渲染。JSONPath 适配器同时修复转义引号、反斜杠和 Unicode 键名解析，树中复制的路径可直接用于提取。

## 文件压缩内核

`lib/compression-files.ts` 在字节层处理 GZip、Zlib、Deflate 和 Brotli。DEFLATE 系列使用有背压的 Worker，Brotli 使用有输出大小限制的 WASM 流；均可取消。GZip 逐成员校验 CRC／长度，Zlib 校验 Adler-32。

`lib/zip-tools.ts` 先读目录元数据，按选定项提取并核对 CRC32 和长度；打包时逐文件压缩。支持 ZIP64 元数据、UTF-8／CP437／GB18030 文件名及 Unicode Path 扩展，拒绝越界和分卷记录；加密、未知压缩方法、不安全路径或过大文件可列出但不可提取。单文件／归档输入上限 64 MB，解压或打包数据合计上限 128 MB，最多 2,000 项。

压缩页新增文件工作区：目录导航／搜索、跨目录选择、UTF-8／Hex／常见图片预览、所选文件提取与 ZIP 打包、多文件／文件夹打包和包内路径编辑。文件编解码支持四种压缩格式及反向处理，下载链接在结果存在期间保持有效。原编码文本工作区和带 `op` / `input` 参数的链接仍可使用。

新增 `compression-file`、`zip-directory` 节点。传递的原始字节会按文件头识别 MIME，旅程对 ZIP／压缩文件提供相应建议；步骤超时会中止底层 Worker。`lib/file-signature.ts` 为文件识别的公共模块，Hex 工具继续保留原有导出接口。

## CSV / JSONL 日志

`lib/tabular-tools.ts` 供 CSV 页的日志工作区与 `tabular`／`tabular-file` 节点复用。UTF-8 文件按 64 KB 块读取，处理跨块引号、换行和多字节字符；CSV 保留原字段文本，JSONL 拒绝会丢失精度的整数／非有限数值。记录保留从 1 开始的原始行号，错误记录跳过并统计，最多保留 1,000 条诊断。

支持多个 AND 筛选、列选择、稳定排序、分组计数和完整 CSV／JSON／JSONL 导出。页面按 50 行分页，最多预览 20 列／每格 240 字符，可查看完整行 JSON 并继续到数据旅程。分组区分缺失、null 和数值／字符串类型，计数字段与分组字段重名时自动增加下划线。旧格式转换工作区与带参数链接保留。

输入最多 64 MB／100,000 条／256 列，单条最多 1M 字符、嵌套 64 层、累计 100 万个值；展开后的 JSON 最多 32M 字符，导出最多 64M 字符，避免长表头的重复展开造成内存膨胀。解析与查询支持中止，修改输入或条件后旧结果立即失效。

## Unicode 字符检查

`lib/unicode-tools.ts` 供独立 Unicode 页和同名画布节点复用。逐码点报告 UTF-16 偏移／单元、UTF-8 字节、转义表示、通用类别和字素簇编号，标记空白、控制、默认可忽略、双向控制、组合标记及变体选择符。孤立代理项保留诊断，UTF-8 字节返回 null，禁止规范化输出伪装为有效标量序列。

支持 NFC／NFD／NFKC／NFKD，报告检查实际输出文本；最多 20,000 个码点／100,000 个 UTF-16 单元，规范化展开后重新检查限制。页面每页 100 项，可搜索中英文属性、筛选带标记字符和下载完整报告／文本。空白输入允许运行，字符簇使用浏览器 `Intl.Segmenter`，属性数据随浏览器 Unicode 版本。规范化语义依据 [Unicode UAX #15](https://www.unicode.org/reports/tr15/)。

## 文本行处理

`lib/text-line-tools.ts` 与 `text-lines` 页／节点共享空白清理、保留首次出现的去重、稳定排序、前后缀、列选择和集合操作。数值排序使用十进制有效数字与数量级比较，避免浮点舍入；支持长整数、小数及指数绝对值不超过 1,000,000 的科学计数法。非法数值或缺列报告原始行号。

集合操作先分别去重，保留 A 的原文和顺序，并集／对称差追加 B 独有行；A 为空时也可计算。列规则支持 1 开始的列号、升序范围及重排，按字面分隔符或连续空白拆分，不替代 CSV 引号解析。可配置 LF／CRLF 和末尾换行，输入末尾终止符不虚增空行。

两组输入合计最多 8M 字符／100,000 行，输出最多 16M 字符，拼接前检查前后缀和重复列造成的展开。每页预览 100 行、每行 1,000 字符，复制和导出使用完整结果；结果可直接成为新输入或继续到数据旅程。

## URL 参数编辑

`lib/url-tools.ts` 与 URL 页面／节点共享解析和重组。支持 HTTP(S)、WS(S)、FTP、file、IDN／IPv6，以及显式基础 URL 下的相对地址。参数使用有序数组，保留重复键、裸参数、空值、空段、空查询／片段标记；每个字段独立保留未编辑的百分号编码，支持百分号与加号空格样式。

页面可逐条启用、增删、重排参数并编辑协议、主机、端口、编码路径及片段。解码视图不用于重建路径，避免 `%2F` 改变分段；无效百分号／UTF-8 显示诊断并保留原始字段。拒绝孤立代理项、非法端口／路径与超过 65,536 字符或 2,000 参数的输入；主机、默认端口及路径遵循 [WHATWG URL 标准](https://url.spec.whatwg.org/)。参数按 50 条分页，修改后即时重组，失败时清空可复制结果。操作仅处理文本，不请求目标 URL。

## MessagePack / CBOR

`lib/binary-codecs.ts` 依据 [MessagePack 规范](https://github.com/msgpack/msgpack/blob/master/spec.md) 和 [RFC 8949](https://www.rfc-editor.org/rfc/rfc8949.html) 提供有界编解码。扩展 JSON 使用 `$binary`、`$bigint`、`$number`、`$map`、`$msgpackExt`、`$cborTag`、`$cborSimple` 和 `$undefined` 保留特殊类型；普通对象与保留标签重名时用 `$object` 包裹。非字符串／重复映射键保留为键值对列表，整数值浮点与整数键区分表示。

MessagePack 扩展含时间戳均保留原始载荷；无效 UTF-8 字符串通过 `$msgpackString` 暴露原始字节。CBOR 支持半／单／双精度浮点、不定长容器及字符串、bignum 和未知标签；编码输出明确容器长度与 64 位浮点，不承诺保留原始分块或浮点宽度。拒绝尾部多余数据、保留值、截断及越界长度，读取前检查范围和工作量。

二进制上限 8 MB，扩展 JSON 16M 字符、100,000 值、64 层，JSON 解析前检查 token／嵌套预算。`lib/binary-codec-tools.ts` 供页面、文本节点及文件节点复用，文件输出保留 File 类型，支持反向处理、下载和 JSON 树；异步文件读取结果有版本及中止保护。共享 Hex 转换改为分块编码／直接解码，避免为每个字节分配临时数组项。测试含规范独立字节样例、长度边界、特殊类型、格式错误和页面任务失效。
