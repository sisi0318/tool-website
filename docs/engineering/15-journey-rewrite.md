# 数据旅程页面重做

产品定位见 [[10-data-journey]]。旅程的卖点是“走过的路自动变成流程”，但重做之前界面上几乎看不到这条路。这次重做的是页面这一层：`lib/journey/` 里的树、引擎、序列化和建议矩阵基本没动。

## 重做之前的问题

- **轨迹只是一排小标签，写的是工具名。**“编码解码”说明不了这一步是 Base64 解码还是 URL 编码。
- **回头看前面的步骤，后面的步骤就消失。** 数据里只记了“选中哪个节点”，轨迹从根画到它为止。回到第 2 步后，第 3、4 步要去分支抽屉里才找得回来。
- **屏幕上永远只有当前这一步的值**，桌面端一条窄列，两边大片留白。
- **改参数、选工具、看分支都是弹窗**，弹出来就盖住正在处理的数据。
- **标题栏七个没有文字的图标**，分不出主次。
- **“更多工具”按名字全排**：手里是一段 JSON，先看到汇率、温度、密码生成。
- **页面组件 840 行、16 个状态变量。** 几种模式和七种对话框，靠每个处理函数手动清五到十个状态来切换；运行、取消、报错的模板重复了五遍。

## 现在的样子

桌面端左边是步骤，右边是选中那一步的详情；窄屏上步骤竖排，选中的那一步就地展开。

- **步骤写的是做了什么，后面跟着结果摘要**：“Base64 解码 · 76 个字符 · JSON”。
- **整条路一直在**。选中哪一步只决定展开的是谁。
- **从路中间继续会另开一条路**，分叉处标着“这里还有 N 条路”，原来那条留在分支里。
- **参数在详情区里就地改**。纯计算的工具停手 350 毫秒后自动重算这一步和它后面的所有步骤；算不出来时原因显示在表单旁边，结果区仍是上一次成功的值。
- **标题栏分了主次**：“应用到新数据”和“分享路径”带文字放在外面，保存、打开、新建、发往画布、模板收进“更多操作”。
- **“更多工具”分成“推荐”和“其他工具”两段**。

## 几个设计决定

### 选中的节点和这条路的末端分开记

`Journey` 多了一个可选的 `tipId`：屏幕上这条路的叶子。只在选中的不是末端时才写，所以走到头的旅程存下来和以前一模一样，旧存档不用迁移。读的时候一律走 `getTipId`：它校验这个值，失效时（旧存档、末端所在的子树被删）从选中的节点往下，每次走最近创建的子节点。

分享、发往画布、“从头重新执行”用的都是屏幕上这条路（根 → 末端），不再是根 → 选中的节点。回头看着第 2 步点分享，带走的仍是整条路。

### 步骤的名字从配置对回建议矩阵

`describeStep` 把步骤的工具和配置对回建议矩阵里已有的动作短语。短语没写明的下拉选项必须还停在默认值才算对上：“格式化 XML”没写操作类型，靠的是默认值，换成 XPath 查询就不该再叫这个名字。对不上时显示工具名加上偏离默认值的选项，例如“哈希计算 · SHA-2-256”。

没有把短语存进节点：用户改了参数，存下来的名字就过期了。

### 哪些步骤边改边算

`canRerunLive` 排除了会联网的、要手动执行的、适配器自己放宽了超时的（OCR 这类），以及输入是文件或超过 20 万字符的。这些步骤的参数区有一个“重新运行”按钮，参数没变也能点（汇率、HTTP 请求会想再跑一次）。

边改边算的那次运行不锁界面，新的改动会顶掉还没算完的那一次；下游算失败时不弹提示，步骤列表上那几步标成“需要重算”。

### 页面状态是一个 reducer

`lib/journey/session.ts`。一屏一种形状：输入、待导入（分享链接或模板）、传入数据被拦下、旅程中。旅程只存在于“旅程中”这一屏里，弹层同一时刻只有一个，换屏时由 reducer 清掉。被导入流程挡在后面的旅程记在 `parked` 里，放弃导入时原样回来。

行为和副作用在 `app/journey/use-journey-session.ts`：读地址栏、自动保存、运行与取消、对旅程的每一种改动。页面组件只负责摆放。

### 加一步之前要不要先填参数

没变：没有参数、没有副作用的工具选了就跑；有参数要填的、会联网的、要手动执行的，先弹参数面板确认。面板（`StepSheet`）现在只管这一件事，已经在路上的步骤不再经过它。它和详情区的参数区共用一份表单 `StepConfigForm`。

## 没有动的

- 分享链接、模板、工具交接的地址格式，以及本地存储格式。已经发出去的链接和已保存的旅程照常能用。
- 输入页、模板页、七个对话框的内容。它们只是改成了按需加载。
- 引擎、序列化、建议矩阵的内容。建议矩阵里“看数据的样子才给出的建议”从函数体里挪进了一张表，行为不变。

## 行为由哪些测试守着

| 行为 | 测试 |
|---|---|
| 末端的记录、选中、分叉、旧存档、删除末端后的回退 | `lib/journey/trail.test.ts` |
| 步骤命名与结果摘要 | `lib/journey/describe.test.ts` |
| 工具排序 | `lib/journey/rank.test.ts` |
| 屏幕与弹层的切换 | `lib/journey/session.test.ts` |
| 参数区：停手后重算、连续改动只发最后一次、失败就地显示、过期的结果作废 | `components/journey/StepSettings.test.tsx` |
| 步骤列表 | `components/journey/StepList.test.tsx` |
| 回头看、从中间分叉、就地改参数并重算下游、刷新后回到原处 | `app/journey/trail.test.tsx`，`e2e/journey.spec.ts` |
| 传入数据、存档与撤销、发往画布的确认 | `app/journey/transfer.test.tsx` |
| 换输入重算全部分支、编辑输入 | `app/journey/replace-input.test.tsx` |
| 取消运行 | `app/journey/cancel.test.tsx` |
| 输入没随存档恢复 | `app/journey/restore-input.test.tsx` |
| 步骤视图的无障碍扫描（浅色、深色） | `e2e/journey.spec.ts` |

原有四个页面测试断言的行为都保留了；测试本身改了驱动界面的那几行（菜单、按需加载的对话框），其中“在步骤面板里取消重算”改成了“在参数区取消重算”，因为那个面板不再用于已有步骤。

## 还没做的

- **参数的名字和选项还是英文**（Category、Algorithm、Encode）。它们写在适配器里，画布也用同一份，没有接进翻译。以前藏在弹层里，现在就在详情区，更显眼了。
- **分叉处的标记打开的是整棵分支树**，不是只列这一处的几条路。
- **窄屏上选中的步骤展开后内容较长**，后面的步骤被推得比较远。
- **不能并排对照一步的输入和输出**。
