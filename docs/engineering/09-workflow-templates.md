# 流程模板

数据旅程的空白输入页和已运行旅程的顶部工具栏提供模板入口。`lib/journey/templates.ts` 定义六套只含本地工具的流程：图片 OCR 整理、WebP 与 Data URL、NFC 名单清理去重、CSV 转 JSON、Base64 JSON 解码、JSON 转 YAML。`/journey#template=<id>` 只接受白名单模板 id，不从 URL 接收额外配置。

模板转换为既有 SharedJourneyPath，并沿用工具注册、端口兼容、默认配置补齐和分享路径审查。选择模板只展示步骤和示例，不执行；运行前仍可恢复原草稿。每一步生成单独 JourneyNode，取消或失败仅保留输入与已完成前缀，用户可回看、修改步骤参数并重算后续分支。

顺序执行引擎接收可选 AbortSignal 和步骤进度回调。外部取消立即结束等待，并传给执行适配器；OCR 等支持信号的工具会终止 Worker。不支持信号的原生操作可能继续到返回，但其迟到结果不会进入旅程。各工具原有超时仍保留，OCR 为 5 分钟，普通步骤默认 30 秒；事件监听器和定时器在结算后清理。

图片输入检查真实 PNG/JPEG/WebP 头部，限制 20 MB、2000 万像素；文本文件只解码 UTF-8，最多 4 MB。名单模板最多 20000 字符，其他文本模板最多 100 万字符。文件选择或示例载入后需要点击“运行模板”，不自动开始。图片路径的“应用到新数据”可重新选择文件。

CSV 模板显式关闭 dynamicTyping 并启用 strict，保留前导零、长编号、空单元格和字面布尔值，解析错误停止流程。CSV 工具及既有工作流的默认行为保持不变，可在步骤配置中改动这两个选项。最后一步由 string-to-file 生成正确扩展名文件；网页图片模板第一步也可单独下载 WebP。

流程结果继续使用既有保存、分享和转入画布能力。文件本体不写入本地存档，恢复或转入画布后需重新选择；模板入口和输入说明明确这一点。模板不是用户内容备份，启动时明确说明会替换当前草稿。
