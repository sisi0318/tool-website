# 图片转 SVG

PNG、JPEG 和 WebP 在独立 Worker 中解码与描摹。VTracer 的 WASM 内核由站点自身提供，浏览器不调用转换 API，也不上传图片。输出仅包含 SVG 路径、分组和几何信息，预览使用 Blob 图片地址，不把 SVG 作为 HTML 插入页面。

## 两种精度

像素保真模式保留采样后的像素轮廓，默认使用每通道 2 级的颜色步长。它能更准确地保留小字、细线和插画，但放大后仍能看到像素形状，文件也明显更大。平滑模式将轮廓拟合为曲线，适合图标、Logo 和平涂插画，可调轮廓细节。

颜色分层在进入内核前完成，内核使用 `colorPrecision=8`、`layerDifference=0`。这避免连续渐变在分层聚类时被合并成一整块颜色；不能直接删除这个预处理步骤。输入中不存在的细节不会被恢复，位图中的文字也不会变为可编辑文本。

保留透明区域时，以 50% alpha 为边界输出透明或实色；用户可以选择铺白底来保留半透明阴影叠加后的观感。动态 PNG/WebP 只处理第一帧。

## 边界与生命周期

文件限 20 MB、源图限 2000 万像素。读取头部尺寸后才创建图片预览或解码，最长描摹边可选 512–2048 px，缩放后的实际尺寸会显示在结果中。工作像素不超过 2048²，颜色过渡行段不超过 36 万，输出不超过 25 万条路径或 24 MB。

每次任务拥有独立 Worker，结束、异常、取消和 45 秒超时都会终止 Worker。文件、参数切换清除旧结果；异步示例读取和任务回包受版本标识保护。图片与 SVG 的 Object URL 在更换或卸载时释放，不写入浏览器持久存储。

`scripts/copy-vtracer-assets.mjs` 校验锁定版本与生成绑定的哈希，只替换 Node 文件读取初始化和导出语法。算法二进制不变。静态资源在首次使用时加载，使用版本化路径缓存，不进入全站预缓存；来源与许可证见 `vendor/vtracer/`。

## 精度验证

同一浏览器中对 512×512 的透明图标、细线文字、平涂插画和连续渐变进行原图 / SVG 对照。以白底合成后每 RGB 通道的平均绝对差作辅助指标，同时进行视觉检查。像素保真模式的一次测试结果分别约为 0.44、0.95、0.39、0.50（每通道范围 0–255）。它们是特定样本的测量值，不代表任意图片的精度保证。

其中插画 SVG 约 3.8 MB，渐变约 4.2 MB；说明高保真输出可能比原图更大。纯路径检查、真实 WASM 渐变回归测试、图片尺寸预检、取消与迟到回包测试共同覆盖关键行为。
