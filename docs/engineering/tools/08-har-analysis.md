# HAR 网络日志分析

`/tools/har` 读取 UTF-8 HAR 1.2 JSON（忽略 BOM），在独立 Worker 中保留原始日志，仅将精简请求行和选中请求的有限详情发送给页面。支持 64 MB、20000 请求、2000 页面；每次作业 60 秒，清空、重载和卸载终止 Worker，消息 id 隔离过时响应。请求列表每页 100 条，筛选、排序和导出覆盖所有匹配记录。

测量语义遵循 [HAR 1.2 规范](https://www.softwareishard.com/blog/har-12-spec/)：耗时采用 `entry.time`，未知、缺失或负值保留 null；TLS 包含于 connect，不参与额外累加。传输字节优先取有效 `response._transferSize`（浏览器扩展，零也有效），否则仅在 headersSize 与 bodySize 都已知时相加。不用解压后 content.size 填补传输大小。中位数与最近秩 P95 只使用已知耗时；界面显示样本数、未知传输条数和已知传输总量，JSON 保留 null，CSV 以空值表示未知。

失败包括 HTTP >=400、状态 0 或记录的 `_error`。重复按整个文件中的方法与完整 URL 判断，不比较请求体、不宣称是可删除的冗余请求；摘要的重复组数量仅统计筛选结果。主机、页面、方法、文本及慢请求阈值均可筛选。瀑布图以筛选后的记录时间跨度为坐标，分段不重复叠加 TLS；缺少开始时间或耗时的条目不虚构柱状图。

默认遮盖 URL 查询值、账号密码、凭证类头部与正文；显式开关可显示原文。导出 CSV/JSON 仅含筛选请求摘要，始终不含头部、Cookie、错误正文或请求/响应正文，默认 URL 查询值遮盖且路径保留。CSV 对全部字段引号转义，并对公式形态内容加单引号。该遮盖不声称完整匿名化。

详情显示最多 300 个头部/参数，每个值最多 8192 字符；请求与响应正文最多各 64000 字符，显示截断情况。HTML 和 base64 等内容作为普通文字显示，不解释执行、不加载日志 URL、不重放网络请求。数据仅在页面及 Worker 内存中存留。
