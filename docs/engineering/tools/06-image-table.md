# 截图表格识别

`/tools/image-table` 复用 [[02-browser-ocr]] 的本地 PaddleOCR 文字框。图像 Worker 将 EXIF 方向规范化，在最长边 1600 像素的预览上扫描连续深色横线与竖线，坐标映射回原图。检测不到网格时按文字高度聚类行中心与列左边界；这是一种位置推测，不使用表格结构模型。

分隔线包含表格外边界，可拖动或输入像素坐标，增删坐标即可增减行列。应用边界后按文字框中心分配单元格，同格多行保留换行。跨越边界或置信度低于 90% 的格子标橙色；范围外文字计数提示。复杂合并单元格、倾斜、多表格和原始格式需人工整理，不推断合并关系。

单元格编辑作为导出数据；重新识别或重新应用分隔线覆盖编辑，界面事先说明。更改文字、边界或导出选项即废弃旧下载。所有图片和文字只在当前页面内存中保存，清空、卸载和取消使用 AbortController 与版本隔离停止作业并忽略迟到结果。

导出在限时 Worker 中动态加载已有 SheetJS。XLSX 默认明确使用字符串单元格，不生成公式；可选将无前导零且不超过 15 位的普通数字转换为数值，长编号、日期、科学计数法和公式形态保留原文。CSV 带 UTF-8 BOM，全部单元格引号转义并保留空白/多行，默认在公式形态内容前加单引号。CSV 无类型信息，Excel 可能自动转换编号，界面建议需精确文本时使用 XLSX。

限制：PNG/JPEG/WebP，单张 20 MB、2000 万像素，动态图片首帧；最多 200 行、40 列、2000 格，单格 32767 字符、总计 200 万字符。图像处理/导出 60 秒限时，OCR 继承单次 5 分钟限时，取消后 Worker 终止。
