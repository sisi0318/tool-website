# 图片隐私打码

`/tools/image-redact` 复用 [[02-browser-ocr]]，提取手机号、显式国际号码、邮箱和中国大陆身份证号的格式候选。号码匹配不代表信息完整或号码有效；界面要求核对原图并允许手动画框补充头像、姓名等内容。

自动选区使用整行 OCR 四边形的轴对齐边界，外扩至少 3 像素或行高的 18%，避免以字符平均宽度猜测遮盖范围。支持勾选、移除、撤销、缩放和原图坐标微调；再次检测保留手动选区并替换自动选区。

预览和导出使用相同的 EXIF 方向归一化。工作线程验证输入头、实际尺寸、格式、选区数量和几何值；导出尺寸必须与预览一致。选区向外取整到完整像素，以不透明黑色或白色写入新画布，再编码 PNG / JPEG，不携带源文件元数据或底图图层。PNG 保留未覆盖位置的透明度，JPEG 先铺白底。动画只处理首帧。

只有点击确认生成后才提供下载或继续处理；候选预览是半透明标注，不作为结果导出。修改选区、颜色、格式或重新检测立即清除旧结果。文件与选区只保留在组件内存，不写本地存储。

输入上限 20 MB、2000 万像素，最多 2000 个区域，输出上限 64 MB。读取与生成线程 60 秒超时，识别使用 OCR 的 5 分钟上限；取消或卸载终止线程，版本标记拦截过期结果。
