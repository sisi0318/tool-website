# 图片对比

`/tools/image-diff` 在限时 Worker 内规范化 EXIF 方向并解码 PNG/JPEG/WebP。比较使用原始像素，不缩放：A 为基准，B 左上角对齐或按整数像素居中，再应用有符号偏移。比较画布覆盖两图外接矩形，负偏移向正画布坐标平移。

重叠区比较预乘 RGB 与 alpha 的最大通道差，严格大于用户阈值才算变化；全透明像素的隐藏 RGB 被忽略。单图覆盖区始终算差异，两个图都未覆盖的画布区域不计入分母。统计包括差异数、有效比较像素数、重叠数、仅 A/B 覆盖数与差异外接框。

差异 PNG 在原分辨率画布上用不透明红色标记变化，未变化区使用浅灰上下文，未覆盖区透明。JSON 记录文件名、规范化尺寸、选项、坐标布局与统计。滑动/叠加视图使用最多 1800 边长预览；两侧分别裁剪，使透明 A 区域不会错误露出 B。阈值与位置变化废弃旧结果，显示模式、缩放和分隔位置只改变预览。

每图 20 MB / 2000 万像素，对齐后画布最多 2000 万像素、边长 32768，PNG 输出上限 64 MB。每个 Worker 作业 60 秒，加载握手完成后派发消息；取消、清空和卸载终止 Worker，版本号拒绝迟到结果。动态图只处理首帧。
